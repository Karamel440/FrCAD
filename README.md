# FrCAD

**FrCAD** — набор библиотек и плагинов на C++ для автоматизации AutoCAD, построенный на базе Autodesk ObjectARX SDK.

Проект предоставляет собственные абстракции для работы с базами данных DWG, графическими объектами, геометрией и специализированными картографическими операциями.

## Библиотеки

FrCAD состоит из набора библиотек, расширяющих возможности Autodesk ObjectARX SDK и предоставляющих более удобный интерфейс для разработки приложений AutoCAD.

| Библиотека | Назначение |
|---|---|
| **FrMain** | Базовая инфраструктура, управление базами данных DWG, обработка исключений и вспомогательные средства |
| **FrEntities** | Высокоуровневый интерфейс для создания и изменения графических сущностей |
| **FrEditor** | Инструменты взаимодействия с редактором AutoCAD и пользовательским вводом |
| **FrMap** | Работа с картографическими объектами, условными знаками и правилами их представления |
| **FrCurves** | Геометрические операции над кривыми (в разработке) |

Библиотеки предназначены для совместного использования, но разделены по функциональной ответственности.
