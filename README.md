# FrCAD

**FrCAD** — набор библиотек и плагинов на C++ для автоматизации AutoCAD, построенный на базе Autodesk ObjectARX SDK.

Проект предоставляет собственные абстракции для работы с базами данных DWG, графическими объектами, геометрией и специализированными картографическими операциями.

## Основные компоненты

- **FrMain** — базовая инфраструктура и управление объектами AutoCAD.
- **FrEntities** — работа с графическими сущностями.
- **FrMap** — специализированные инструменты для картографических чертежей.
- **FrCurves** — библиотека для работы с кривыми (в разработке).
- **FrWells** — анализ и обработка колодцев.
- **FrSheets** — отдельный плагин проекта.

## Технологии

- C++
- Autodesk ObjectARX SDK
- Visual Studio 2022
- Windows / x64

## Статус проекта

Проект находится в активной разработке. API и внутренняя структура библиотек могут изменяться.
