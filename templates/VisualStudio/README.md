# Шаблоны проектов Fr для Visual Studio 2022

| Шаблон | Куда создавать проект | Результат |
| --- | --- | --- |
| Fr ARX Plugin | `plugins` | `.arx` для AutoCAD 2026 с командой `<имя проекта>HELLO` |
| Fr Static Library | `src` | `.lib` с примером функции и заголовком |

В меню «Создание проекта» найди шаблон по имени и выбери расположение внутри репозитория Fr. Дополнительная папка решения допустима. Для проекта вне репозитория задай свойство MSBuild `FrRoot` с путём к Fr.

Оба шаблона используют настройки из `build`, C++20, v143, Windows SDK и конфигурации Debug и Release x64. Debug сохраняет отладочные символы и использует CRT `/MD` для совместимости с ObjectARX. Результаты сборки сохраняются в выходном каталоге проекта. После успешной сборки Release x64 ARX дополнительно копируется в Картографию. Статическая библиотека копируется в `lib` SDK Fr, а заголовки из проекта — в `inc`.

Fr ARX Plugin подключает FrMain, FrEntities, FrEditor и FrMap через Fr.Libraries.props. Fr Static Library собирает свою библиотеку; зависимости указываются при компоновке конечного приложения или плагина.

Чтобы установить шаблон вручную, упакуй содержимое его папки в ZIP так, чтобы `.vstemplate` лежал в корне архива. Скопируй ZIP в каталог пользовательских шаблонов проектов, указанный в параметрах Visual Studio.
